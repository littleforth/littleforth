# Contributing

Bug reports, ideas and questions: open an [issue](https://github.com/littleforth/littleforth/issues).

Code: open an issue first to talk it over. Then a pull request, with `make check`
passing (see [docs/building.md](docs/building.md)).

Drivers and examples in Forth are especially welcome: put drivers in
`lib/rp2350/drivers/`, one file per peripheral, and examples in `examples/rp2350/`.

By contributing you agree that your work is released under the MIT licence.
